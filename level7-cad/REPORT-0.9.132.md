# LEVEL7 and MTM 0.9.132

1. **قائمة X مثل GRAFIS**
   - جدول مكثف: **X | الاسم | MTM | Standard** (القيمة الأساسية بالأصفر) **| عمود لكل مقاس**.
   - خانة المقاس الفارغة تأخذ القيمة الأساسية، وتظهر رمادية.
   - شريط علوي: **⊕** لإضافة قياس، و**✕** لحذف الصف المحدد.
   - شريط سفلي: بحث بالاسم أو الرقم، وزر نسخ الجدول كاملاً ليُلصق في إكسل.
   - عمود MTM باقٍ كما طلبت.
2. **خطوة الزاوية تبقى كما اخترتها** (مثل 90°) حتى تغيّرها، حتى بعد إغلاق البرنامج. وكذلك خطوة تقريب النقاط الحرة.
3. **لوحة النقاط تبدأ نظيفة:** بعد انتهاء رسم الخط أو المنحنى أو إغلاق الأداة، تعود قيمها كلها 0 ووضعها إلى النقطة العادية (•).
