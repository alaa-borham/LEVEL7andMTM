# LEVEL7 and MTM 0.9.119

1. **شريط الأوامر القديم بالاختصارات داخل تصميم LEVEL7**
   - الشريط مثبت أعلى الرسم بنفس شكل صندوق الأوامر. الأوامر واختصاراتها:

     | الأمر | الاختصار |
     |---|---|
     | Save | Ctrl+S |
     | ملء الشاشة | F6 |
     | خطوات البناء | F5 |
     | X | Ctrl+X |
     | Z | F11 |
     | المقاسات | Ctrl+G |
     | القطع | — |
     | تصغير / تكبير | − / + |
     | Undo | Ctrl+Z |
     | Redo | Ctrl+Y |
     | New | Ctrl+N |
     | Open | Ctrl+O |
     | AAMA | Ctrl+E |
     | DXF / PLT | — |

   - الاختصارات تعمل والتركيز داخل الرسم أيضاً.
   - أُخفيت تبويبات المحرك المكررة، والصفحة المفتوحة تظهر مضاءة في الشريط.
2. **أدوات الرسم على صفحة فارغة**
   - كانت أدوات الخط تطلب نقطة موجودة، فلا يحدث شيء عند النقر على مساحة فارغة.
   - الآن ينشئ النقر على مساحة فارغة نقطة حرة في مكانه، كما في GRAFIS. مثلاً «خط بزاوية وطول» يعمل من أول نقرة، و«خط بين نقطتين» يعمل بنقرتين.
3. **أُزيلت مربعات الشبكة من الرسم**، وتبقى علامة نقطة الأصل فقط.
