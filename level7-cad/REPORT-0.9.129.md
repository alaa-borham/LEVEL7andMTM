# LEVEL7 and MTM 0.9.129

## معادلات Z لم تعمل
- **السبب:** كُتبت `X2/2` في خانة **الوصف** (الخانة العلوية)، وبقيت خانة المعادلة تحتها 0، فكانت Z1 = 0. تصميم الخانتين كان مربكاً.
- **الإصلاح:** جدول على طريقة GRAFIS: **Z | Formula (المعادلة) | Text (الوصف) | Value (القيمة)**.
  - المعادلة أولاً، ومكتوب قبلها «Z1=».
  - Enter يحفظ وينتقل للسطر التالي.
  - المعادلة الخاطئة يظهر سببها بالأحمر في خانة القيمة.
  - «إضافة معادلة» يضع المؤشر مباشرة في خانة المعادلة.
  - إن كانت معادلة مكتوبة في خانة الوصف والمعادلة 0، تُنقل تلقائياً إلى مكانها. لذلك تصبح Z1 عندك = 240.

## مساعد Z (Z value assistant)
- لا يفتح إلا عند الطلب: بزر **ƒx** بجانب كل معادلة، أو بزر **«ƒx مساعد المعادلات»** للسطر الحالي.
- **طريقة الحساب:** معادلة عادية، أو **حالات**: IF … THEN … / ELSE IF … THEN … / ELSE … (تُكتب CMDIF كما في GRAFIS).
- **عناصر المعادلة:** قائمة X أو Z بالاسم والقيمة، تُضاف بنقرة في موضع المؤشر.
- **المعاملات:** = < > <> <= >= و+ − × ÷ والأقواس.
- «✓ اعتماد» يتحقق من المعادلة ويحفظها. النافذة تُسحب إلى أي مكان.

## لوحة النقاط
- بجانب كل قيمة فيها (% وmm وس/ص) قائمة **XZ** لاختيار قياس أو متغير، وتبقى النقطة مرتبطة به.
- كلمة mm صارت تظهر بخط عادي، بعد أن ظهرت مربعات على جهازك.
