# LEVEL7 and MTM 0.9.148 — LEVEL7 هو الافتراضي، ‎.level7 بدابل كليك، زر Export، وإدارة مكتبة القياسات

| طلبك | التنفيذ |
|---|---|
| «تصميم LEVEL7» هو الافتراضي للنظام | البرنامج يفتح مباشرة على شاشة التصميم، بآخر تصميم كنت تعمل عليه (من الحفظ التلقائي)، أو بتصميم فارغ. |
| الخيارات الأخرى كأيقونة داخل النظام للمستقبل | زر **GRAFIS** في شريط الأوامر، وفيه: فتح ملف GRAFIS (MDL)، وملف MDL جديد، ومثال X/Z، ومساحة عمل MDL. أي منها يغلق شاشة التصميم ويفتح مساحة MDL. وزر × أعلى الأدوات ما زال يعيدك إلى مساحة MDL، والعودة إلى التصميم من File. |
| فتح ملف التصميم بدابل كليك عليه | **امتداد جديد ‎`.level7`** لملفات التصميم. البرنامج يسجّله في Windows لحسابك فقط: يظهر الملف بأيقونة LEVEL7، ويُفتح بدابل كليك داخل التصميم مباشرة. وإذا كان البرنامج مفتوحاً، يُفتح الملف في نفس النافذة. |
| تغيير الامتداد ‎.level7.json | لم يكن ممكناً ربط ‎.level7.json بالبرنامج، لأن Windows يقرأ آخر امتداد فقط (‎.json)، فتُفتح كل ملفات json بالبرنامج. لذلك صار الامتداد ‎`.level7`. |

| أزرار التصدير في صفحة المقاسات تكون أيقونة مستقلة | زر **Export** في شريط الأوامر، وفيه: AAMA للمقاس الحالي (Ctrl+E)، وAAMA لكل المقاسات، وAAMA مع قواعد التدرج + RUL، وPLT للمقاس الحالي، وPLT لكل المقاسات، وDXF خطوط البناء. أُزيلت أزرار AAMA وDXF وPLT المنفصلة من الشريط، فصار فيه مكان أكثر. |
| إنشاء المكتبة وإضافة المنتجات وقياساتها وتعديلها من صفحة المقاسات | زر **📚 مكتبة القياسات** في صفحة المقاسات، وفي نافذة X. التفاصيل تحت الجدول. |

**تفاصيل إدارة مكتبة القياسات:**
- **＋ منتج جديد:** تكتب اسم المنتج واسم المقاس الأساسي، ثم تضيف قياسات X (الاسم والقيمة)، والمقاسات بأعمدة (الاسم وقيمة كل قياس). الخانة الفارغة تأخذ القيمة الأساسية.
- **✎ تعديل:** يعدّل أي منتج داخل المكتبة نفسها، ولا يتغير التصميم المفتوح.
- **استخدام:** ينسخ المنتج إلى التصميم.
- **أيضاً:** حذف منتج، والبحث، والتصدير والاستيراد كملف.

**الملفات القديمة ‎.level7.json:**
- ما زالت تُفتح من داخل البرنامج: File ← فتح تصميم LEVEL7.
- بعد فتحها، احفظها مرة واحدة (Ctrl+S) فتُحفظ بالامتداد الجديد ‎.level7، وبعدها تُفتح بدابل كليك.

**التسجيل في Windows:** يتم تلقائياً عند أول تشغيل بعد التحديث، ولا يحتاج صلاحيات مدير. إذا لم تظهر الأيقونة على الملفات فوراً، أعد تشغيل مستكشف الملفات أو الجهاز.
