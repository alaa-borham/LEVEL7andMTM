# ربط LEVEL7 CAD مع نظام MTM ونظام التعشيق

هذا الدليل لمبرمجي نظام MTM ونظام التعشيق عندكم.

## الفكرة

```
نظام MTM ── قياسات الزبون (JSON أو CSV) ──▶ LEVEL7 (سطر الأوامر)
                                                │  يبني الباترون بقياسات الزبون
                                                ▼
                         ملفات AAMA / PLT + تقرير JSON ──▶ نظام التعشيق
```

- الباترون يُرسم مرة وحدة في البرنامج، وينحفظ بملف `.level7.json`.
- لكل طلب، نظام MTM يشغّل أداة سطر الأوامر ويعطيها قياسات الزبون، فتطلع ملفات القص.
- الأداة ما تفتح أي نافذة، فتقدر تشتغل على الخادم أو في الخلفية.

## 1. ربط أسماء القياسات

في صفحة **«القياسات X»** عمود اسمه **«رمز MTM»**. اكتب فيه اسم القياس مثل ما يجي من نظام MTM، مثلاً `chest` أو `shoulder` أو `الصدر`.

عند الاستيراد، كل قياس ينربط بقياس X بهذا الترتيب:

1. رمز MTM.
2. رقم القياس نفسه، مثل `X7`.
3. اسم القياس في البرنامج.

الحروف الكبيرة والصغيرة والمسافات الزائدة ما تفرق.

- **قياس ما انربط بشي:** ينكتب في التقرير تحت `unknown`.
- **قياس الباترون اللي ما جاء من الطلب:** ياخذ القيمة الأساسية، وينكتب في التقرير تحت `missing`.

## 2. صيغ قياسات الزبون

### JSON (طلب واحد، أو قائمة طلبات)

```json
{
  "customer": "Ahmed",
  "order": "A-1001",
  "unit": "cm",
  "measurements": { "length": 140, "shoulder": 42, "collar": 38 }
}
```

| الحقل | الوصف |
|---|---|
| `customer` | اسم الزبون (أو `name` أو `id`) |
| `order` | رقم الطلب (اختياري) |
| `unit` | الوحدة: `mm` أو `cm` أو `in`. الافتراضي `mm`، أو قيمة `--unit` |
| `measurements` | القياسات: الرمز = القيمة |

### CSV (سطر لكل زبون)

```
customer;order;length;shoulder
Ali;B-1;140;40
سالم;B-2;135;38.5
```

- **الفاصل:** فاصلة أو فاصلة منقوطة أو Tab، ويتعرف عليه البرنامج تلقائياً.
- **الكسور العشرية:** بالنقطة أو بالفاصلة.
- **أعمدة اسم الزبون:** `customer` أو `name` أو `id` أو `الزبون` أو `العميل`. وإذا ما لقى واحد منها، ياخذ أول عمود.
- **أعمدة اختيارية:** `order` أو `رقم الطلب`، و`unit` أو `الوحدة`.
- **باقي الأعمدة:** كلها قياسات.

## 3. أداة سطر الأوامر

**على ويندوز (من البرنامج المثبّت، بدون أي إضافات):**

```bash
"C:\Program Files\LEVEL7 CAD\LEVEL7 CAD.exe" --cli --model thobe.level7.json --order order.json --format aama,plt --out C:\orders\A-1001
```

**بـ Node.js (أي نظام):**

```bash
node level7.cjs --model thobe.level7.json --csv customers.csv --unit cm --out out
```

الملف `level7.cjs` يطلع من `npm run build` داخل `app/dist-cli/`.

| الخيار | الوصف |
|---|---|
| `--model FILE` | ملف الباترون (`.level7.json`). **إجباري** |
| `--order FILE` | طلب أو طلبات JSON |
| `--csv FILE` | زبائن CSV |
| `--unit mm\|cm\|in` | وحدة القياسات (الافتراضي `mm`) |
| `--format LIST` | `aama` و`plt` و`dxf` (خطوط البناء). الافتراضي `aama` |
| `--size NAME` | تصدير مقاس واحد من جدول المقاسات |
| `--all-sizes` | كل المقاسات في ملف واحد |
| `--graded` | AAMA بقواعد التدرج + ملف `.rul` |
| `--out DIR` | مجلد الإخراج |

### الملفات الناتجة

- لكل زبون: `‹رقم الطلب›_‹الزبون›.dxf` و`.plt`.
- دايماً: `level7-report.json`:

```json
{
  "ok": true,
  "files": ["out/A-1001_Ahmed.dxf", "out/A-1001_Ahmed.plt"],
  "errors": [],
  "customers": [
    {
      "customer": "Ahmed", "order": "A-1001",
      "files": ["out/A-1001_Ahmed.dxf", "out/A-1001_Ahmed.plt"],
      "unknown": ["waist"],
      "missing": ["down FRONT R"],
      "errors": []
    }
  ]
}
```

### رمز الخروج (exit code)

| الرمز | المعنى |
|---|---|
| 0 | تم كل شي |
| 1 | بعض القطع فيها أخطاء، مثلاً قياسات غير منطقية |
| 2 | مدخلات خاطئة: ملف ناقص، أو خيار غير معروف، أو مقاس غير موجود |

**ملاحظة لويندوز:** البرنامج المثبّت ما يكتب رسائل على الشاشة. اعتمد على رمز الخروج وعلى `level7-report.json`.

## 4. من داخل البرنامج (بدون برمجة)

1. افتح صفحة **«المقاسات»**، واضغط **«استيراد زبائن (CSV / JSON)»**، واختر وحدة الملف. كل زبون يصير عمود.
2. اختر الزبون من قائمة المقاسات أعلى الشاشة.
3. صدّر AAMA أو PLT.

الزبائن ما يدخلون في التعبئة بالتدرج ولا في قواعد التدرج.

## 5. اللي يحتاج تأكيد من جهتكم

- **صيغة AAMA اللي يقرأها نظام التعشيق عندكم:** أفضل شي ملف مثال يقرأه بدون مشكلة. الدليل على التفاصيل في [user-guide.md](user-guide.md).
- **طريقة استدعاء البرنامج من نظام MTM:** سطر أوامر، أو مجلد مراقَب، أو API عبر HTTP. الطريقة الحالية سطر أوامر، والطرق الباقية تنضاف حسب طلبكم.
